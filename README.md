# DSA Revision — Interview Practice

A growing collection of solved coding problems, organized by topic to support revision and interview preparation.

## How to use this repository
1. Pick a topic from the index below.
2. Try solving a problem before opening the solution.
3. Explain the approach and time/space complexity in your own words.
4. Revisit problems you struggled with after a few days.

## Current focus
- Binary search and search-space reduction
- Sliding window
- Core problem-solving patterns

> Solutions are a learning log, not a substitute for understanding. Rework each problem independently and test edge cases.
